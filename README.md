# Exploratory Analysis of HRV Recovery Following Teacher Burnout

## Overview

This project explores how Heart Rate Variability (HRV) changed during recovery from severe occupational burnout between October 2025 and May 2026.

Using physiological data collected through a WHOOP wearable device, I investigated long-term HRV trends through monthly aggregation and visualisation.

## Research Question

How did Heart Rate Variability (HRV) change during recovery from teacher burnout between October 2025 and May 2026?

## Why HRV?

HRV was selected because it is one of the most widely used physiological indicators of autonomic nervous system recovery and resilience.

Rather than relying on a proprietary recovery score, this project focuses on a direct physiological measurement.

## Tools Used

- Python
- Pandas
- Google Colab
- HTML
- CSS

## Methodology

1. Export physiological data from WHOOP.
2. Import data into Python using Pandas.
3. Group daily observations by month.
4. Calculate monthly mean HRV.
5. Visualise results using an interactive dashboard.
6. Interpret findings within the context of burnout recovery.

## Key Finding

Monthly mean HRV increased from 28.6 ms in October 2025 to 39.0 ms in April 2026 before declining slightly to 36.4 ms in May 2026.

Despite short-term fluctuations, the overall trend suggests substantial physiological recovery following burnout.

## Limitations

- Single-subject observational study
- No control group
- Multiple concurrent life events
- Results are exploratory rather than causal
